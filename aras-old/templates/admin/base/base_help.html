Welcome to Aras

Aras is a modular, metadata-driven Application Framework and ERP built for speed and extensibility. This Help Center provides comprehensive guidance on how to navigate, administer, and develop on the platform.

Navigating the System

Aras uses a modern sidebar navigation grouped by App Modules. You can find installed applications like ERP, CRM, and Settings on the left panel.

  • Global Search: The fastest way to navigate. Use the search bar at the top (or press Cmd+K / Ctrl+K) to instantly find records, pages, or settings across all modules.
  • Dashboards: Most apps have a dedicated dashboard showing KPIs, charts, and recent activities.
Core Concepts
  • Apps: Self-contained modules (like Accounting or Inventory) that add specific business logic to the framework.
  • Resources (CRUD): Most pages you interact with are Data Resources. Aras automatically handles Create, Read, Update, and Delete operations for these.
  • Workflows: Many documents (like Invoices or Purchase Orders) go through states (Draft → Submitted → Approved). Workflows govern these transitions.
Role-Based Access Control (RBAC)

Security is managed at the resource level. Administrators can create Roles and assign specific permissions (Read, Write, Create, Delete, Submit) for each App and Resource. Assign Users to Roles to grant access.

App Manager

Install and manage dynamic apps. The App Manager allows you to load new modules via YAML/JSON definitions or Python manifests without restarting the core engine.

Workflow Engine

A declarative state-machine. Define Custom States (e.g., Draft, Pending, Approved) and rules for transitioning between them, including gating by specific User Roles.

Audit Logs

Every modification to critical data is tracked. The Audit Log records who changed what, showing the exact old and new values for every field modification.

Building on Aras
Code-based apps in the aras/ directory register themselves using a manifest.py file. By defining an AppHelper instance, you automatically generate UI menus, API endpoints, and RBAC entries without writing boilerplate routing code.
All models should inherit from arasCore.lib.base_model.ArasModel. This base class provides built-in support for standard fields (created_at, updated_at), UUID generation, and automatic integration with the Audit Trail system.
Resources defined in your manifest are automatically exposed via RESTful endpoints at /api/<app_slug>/<resource_name>/. The API includes built-in validation, pagination, and sorting.
Need custom business logic? Use Server Scripts for sandboxed Python hooks (Before Insert, After Update, etc.) to modify data on the fly. Use Webhooks to send HMAC-signed outbound events to external systems when data changes.
Important Convention: Never write CSS or JavaScript directly in HTML templates. Use static/css/aras_design.css and external JS files. Always use admin/gen_view_list.html for standard list views.
Frequently Asked Questions
I'm getting an "Unknown column" error in the database.

This happens when there is a mismatch between your SQLAlchemy models and the physical MariaDB tables. Run flask aras fix-db in the CLI to attempt an automatic fix, or use Alembic migrations.

How do I completely reset the database for development?

Use the CLI command flask aras remigrate. Warning: This drops all tables, recreates them, runs migrations, and applies basic seed data. Use flask aras erp-init to seed ERP-specific test data.

A template is missing or showing an error.

Ensure you are using the modern generic templates. Legacy paths like admin/aras_list.html have been deprecated. Use admin/gen_view_list.html and admin/gen_view_form.html instead.

The UI looks broken after an update.

Clear your browser cache or perform a hard refresh (Cmd+Shift+R / Ctrl+F5) to ensure you are loading the latest aras_design.css and JavaScript files.
